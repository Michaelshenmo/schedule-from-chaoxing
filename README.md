## 介绍 / Introduction

本插件基于 [Class Widgets 2 SDK](https://github.com/Class-Widgets/class-widgets-sdk)，通过超星学习通统一登录接口获取当前账号的课表，并生成一个独立的课表配置。

- 使用超星学习通账号自动登录，通过超星课表接口读取课程数据（无需手动导出）
- 自动将课程、教师、地点、周次和上课时间转换为 Class Widgets 2 课表格式
- 同步结果写入独立课表，不会覆盖或修改你正在使用的课表
- 支持分别开关「同步课程」和「同步时间线」
- 启动 Class Widgets 时自动同步一次
- 支持设置自动同步间隔（默认 20 分钟）；设为 -1 时仅保留启动同步和手动同步
- 支持设置课间上限时长（默认 45 分钟）；设为 -1 时不限制，0 表示不填充课间
- 可分别控制启动、定时和手动同步的通知
- 支持从超星课表接口自动读取课程；课表导出文件（本地 `.xlsx` 或下载地址）作为备用来源，默认隐藏，可在插件目录的 `config.json` 中开启
- 课程与时间线可来自不同数据源：课程来自超星/导出文件，时间线来自晋元学生平板终端集控系统
- 时间线服务器只需填写服务端地址（如 `12.34.56.78:1234`），插件自动尝试晋元学生平板终端集控系统时间线接口
- 按获取到的时间线从上到下填充课程类型日程，并在相邻课程空档补「课间」
- 每天的课程、活动和课间写入同一条时间线；课程安排（时间与课程）相同的周次会合并到一条时间线
- 关闭「同步时间线」时不会获取、写入或替换时间线，仅同步课程；目标课表原有时间线保持不变
- 支持「日程映射」：按名称、星期和周次改写课程或时间线的写入名称/时间，或设为不写入课表
- 支持从托盘菜单的快捷入口一键同步课表
- 支持一键切换到目标课表查看同步结果
- 账号密码先验证再加密保存，设置页面不会回显已保存的账号
- 支持配置导入导出；可选择要导出/导入的项目，学习通账号与密码默认不导出，配置文件会记录插件版本

## 使用 / Usage

1. 安装 [Class Widgets 2 SDK](https://github.com/Class-Widgets/class-widgets-sdk) 依赖：

```bash
pip install class-widgets-sdk
```

2. 在终端运行 `cw-plugin-pack` 打包插件：

```bash
cw-plugin-pack
```

3. 在 Class Widgets 2 的「设置」→「插件」中导入并启用插件。

4. 打开「设置」→「插件」→「学习通课表同步」：

   - 输入超星学习通手机号/超星号和密码，点击「验证账号」，验证通过后点击「保存账号」
   - 按需开启「同步课程」和「同步时间线」
   - 设置自动同步间隔（默认 20 分钟；-1 表示仅启动和手动同步）
   - 设置课间上限时长（默认 45 分钟；-1 不限制，0 不填充）
   - 在「通知选项」中分别控制启动、定时和手动同步通知
   - 正常情况下直接使用超星课表接口读取课程；如需使用「课表导出文件」，先将插件目录 `config.json` 中的 `show_timetable_export` 设为 `true` 并重启 Class Widgets
   - 在「时间线服务器」中填写晋元学生平板终端集控系统服务器地址（如 `12.34.56.78:1234`），并填写学校提供的设备 SN
   - 可修改目标课表名称（默认「超星学习通」），或点击「切换课表」查看结果
   - 在「日程映射」中添加规则，按名称、星期和周次改写课程/时间线的名称或时间，或设为不写入课表
   - 在「配置导入导出」中可备份或恢复插件设置；导入后会先勾选需要恢复的项目
   - 点击顶部「立即同步」可手动同步一次，展开「同步详情」可查看请求与返回信息

5. 同步完成后，在 Class Widgets 2 的课表设置中切换到目标课表即可。

## 插件配置

插件目录下的 `config.json` 控制设置页中的可选功能：

```json
{
  "show_timetable_export": false
}
```

- `show_timetable_export`：设为 `true` 时显示「课表导出文件」子菜单，可用于选择本地 `.xlsx` 课表或填写下载地址；设为 `false` 时隐藏该子菜单。修改后重启 Class Widgets（或重新加载插件）生效。

## 同步说明

- 插件会在课表目录中创建或更新独立课表，不会自动切换你当前正在使用的课表。
- 如果目标课表名称已存在，且不是本插件创建的课表，插件会拒绝覆盖，请更换目标课表名称。
- 目标课表由插件管理，手动修改会在下次同步时被覆盖。
- 「同步课程」负责从超星课程列表和课表写入课程名称、教师、地点和课程颜色。
- 「同步时间线」负责写入上课时间段和周次；可在「日程映射」中按名称改写或排除课程、节次；如果超星课表或时间线服务器没有某节课的时间，插件会把课程写成活动类型日程。
- 「日程映射」规则对话框分为「命中规则」和「操作」两个标签页。命中规则包含名称、匹配范围（课程/时间线/同时匹配，单选）、星期和周次（默认全选）；操作包含可选的开始/结束时间、写入名称与「不写入」开关。名称按包含匹配，规则自上而下取第一条，留空字段沿用同步数据。
- 只有所选星期和周次内的时间线会被映射；跨周次的课程会按周次拆分，未选中的星期和周次保持原样。课程规则作用于课程名称和上课时间；时间线规则作用于时间线节次、活动和课间。旧版「排除项」配置会在加载时自动转换为全周、全星期「不写入」规则。
- 无论使用课程接口、接口回退还是 `.xlsx` 课表，都会在相邻课程空档补「课间」；超过「课间上限」的空档不填充，上限设为 -1 时不限制。
- 每个星期只保留按安排区分的时间线：当天所有课程、活动和课间放在同一条时间线，周次安排完全相同的周会合并存储；没有任何日程的周次不写入时间线。
- 关闭「同步时间线」时，插件不会请求时间线服务器，也不会写入或替换时间线；目标课表原有时间线保持不变，课程设置仍会同步。
- 选择 `.xlsx` 课表文件或填写课表文件下载地址后，插件会优先使用该文件，并按时间线的节次顺序填充课程；开启「同步时间线」但目标课表没有可用时间线时，会使用内置的 20 分钟节次时间。
- 设置时间线服务器后，插件会优先使用晋元学生平板终端集控系统返回的节次时间；服务器不可用时不使用超星或目标课表的其它时间线，只同步课程设置，并在同步状态中提示。
- 时间线服务器未返回节次编号时，插件会按时间顺序跳过早自修、课间活动、眼保健操、课后活动、晚自习等非上课时段来推断节次；这些非上课时段会作为活动日程写入，不会占用课程节次。
- 时间线接口支持常见的 `timeSlots`、`periods`、`days` 等字段，节次可包含 `name`、`start`/`end`、`period`、`dayOfWeek`；也支持晋元学生平板终端集控系统教学策略中的 `schedules.weeklySlots`。
- 插件会用设备 SN 向 vendor 服务认证，自动向晋元学生平板终端集控系统注册设备并拉取教学策略时间线；无需管理员令牌。
- 如果设备 SN 认证不可用，也可把 [docs/jinyuan-control-timeline-endpoint.py](docs/jinyuan-control-timeline-endpoint.py) 中的只读路由加入集控系统后端 `backend/routes/teaching.py` 作为备用。
- 课程读取方式与 android-app 一致：登录学习通后访问课表入口，再调用 `course.chaoxing.com/svcourse/new/timetable/getIssuedCourseInfo` 获取全部周次课程。
- 示例：`{"data":{"timeSlots":[{"name":"第一节","start":"08:00","end":"08:40"}]}}`；按星期返回时可用 `{"data":{"days":{"1":[{"name":"第一节","start":"08:00","end":"08:40"}]}}}`。
- 两项都关闭时，自动同步会停止。
- 如果超星学习通账号需要二次验证（如短信验证码），当前版本无法自动同步。

## 账号安全

- 账号密码不会以明文写入配置文件。
- Windows 下优先使用 DPAPI 加密，密文只能由当前 Windows 用户解密。
- 非 Windows 平台使用随机密钥加密，并校验数据完整性。
- 设置页面不会读取或显示已保存的账号；保存后账号输入栏会隐藏，如需更换请先点击「清除账号」。
- 「配置导入导出」的账号与密码使用 `chaoxing_account` / `chaoxing_password` 两个键；导出时留空，导入时账号项默认不勾选，勾选空账号项会清除已保存的账号。
- 导入非空账号时会先验证登录；验证失败时可选择取消导入或只导入其他配置项。
- 导出的配置文件会记录当前插件版本；导入时若配置文件版本过新、过旧或未记录，会先提示并显示当前插件版本与配置文件版本。
- 插件不会上传账号信息到任何第三方服务器，仅用于登录超星学习通。
